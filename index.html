How the refresh works. A GitHub Action runs every morning at 06:00 IST, pulls the Greenhouse, Lever and Ashby job feeds plus the Wellfound listings, filters out anything senior or internship-level, and commits the result. Refresh pulls the newest committed list — it does not scrape live, because a page served from GitHub Pages is not allowed to fetch other sites directly. Roles that appeared in the most recent run are badged new.
Marking a role applied saves it in this browser only — nothing is uploaded anywhere. Use Export on the applications page to keep a copy, and re-import it if you switch browser or machine.
